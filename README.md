# TRUSTBULKERS PERFORMANCE TOOL

Εισαγωγή ENG-004 Excel, αξιολόγηση κύριας μηχανής, διαγράμματα, προαιρετική σύγκριση, PDF και Excel με επεξεργάσιμα διαγράμματα.

## Ανέβασμα στο GitHub

1. Αποσυμπίεσε το ZIP.
2. Στο repository πάτησε **Add file → Upload files**.
3. Ανέβασε όλα τα αποσυμπιεσμένα αρχεία μαζί, απευθείας στο root. Το `index.html`, το `app.js`, το `style.css`, το `xlsx.full.min.js` και το `jspdf.umd.min.js` πρέπει να βρίσκονται στο ίδιο επίπεδο. Αντικατάστησε τις προηγούμενες εκδόσεις τους.
4. Πάτησε **Commit changes** στο branch `main`.
5. Άνοιξε **Settings → Pages**.
6. Στο **Source** επίλεξε **Deploy from a branch**.
7. Επίλεξε **main**, **/(root)** και πάτησε **Save**.
8. Όταν ολοκληρωθεί η δημοσίευση, άνοιξε το URL από το **Visit site**. Αν εμφανίζεται παλιά έκδοση, πάτησε **Ctrl + F5**.

Αυτή η έκδοση δεν χρειάζεται υποφακέλους, GitHub Actions workflow, εγκατάσταση εξαρτήσεων ή build. Τα παλιά αρχεία ελέγχων (`*.test.js`, `check.mjs`) και τα μεμονωμένα report JSON της προηγούμενης μεταφόρτωσης δεν χρησιμοποιούνται από τη σελίδα.

## Δεδομένα

Η σελίδα ξεκινά χωρίς αποθηκευμένα reports. Η επεξεργασία των εισαγόμενων αρχείων γίνεται στον browser. Τα reports και οι ρυθμίσεις αποθηκεύονται τοπικά ανά browser και συσκευή. Σε νέο domain χρειάζεται νέα εισαγωγή των αρχείων.

Τα shop-test references και οι αντιστοιχίσεις πλοίων περιλαμβάνονται στο `fleet-data.js`. Οι πηγές, οι προϋποθέσεις των ορίων και η βάση υπολογισμού εμφανίζονται στο **Rules & sources**. Οι καμπύλες πρόβλεψης πρόωσης παραμένουν εκτιμήσεις αναφοράς.

Οι άδειες των βιβλιοθηκών διατηρούνται στα `SHEETJS-LICENSE`, `JSPDF-LICENSE` και `DEJAVU-LICENSE`.
